☁PhysicalCloud

Uma ponte entre seus dispositivos.

O Physical Cloud é uma ferramenta para transferir arquivos entre dispositivos conectados diretamente por iniciativa dos próprios usuários. A proposta é facilitar o envio e o recebimento de arquivos entre celular, computador e outros aparelhos, sem transformar o Physical Cloud em um serviço de hospedagem ou armazenamento de arquivos.

A ideia central
Você escolhe com qual dispositivo deseja se conectar e decide quais arquivos enviar, receber ou disponibilizar. O Physical Cloud fornece os recursos técnicos para estabelecer a conexão e realizar a transferência; a escolha do outro dispositivo é sua.

Como funciona

  • Os dispositivos estabelecem uma sessão de conexão usando os mecanismos de sinalização do serviço.
  • Após a conexão, a transferência é feita entre os dispositivos por meio de tecnologia de comunicação ponto a ponto (WebRTC).
  • O Physical Cloud não escolhe destinatários por você nem verifica se um arquivo é confiável ou seguro.

Conecte-se somente a dispositivos que você conhece ou nos quais confia. Confira a origem e o conteúdo dos arquivos antes de abrir ou executar qualquer item recebido.

Política de Privacidade

Última atualização: 9 de novembro de 2026

1. Escopo e funcionamento

O Physical Cloud é uma ferramenta de conexão e transferência de arquivos entre dispositivos escolhidos pelos usuários. Não é uma rede social, não seleciona contatos e não se destina a armazenar arquivos em uma nuvem pessoal.

2. IDs, identificadores e dados técnicos

O ID do modo automático (formato PC- seguido de 27 caracteres aleatórios) é gerado no próprio dispositivo e seu texto original permanece no armazenamento local do aparelho. O aplicativo calcula localmente o SHA-256 desse código e envia somente o hash ao servidor de sinalização; o Supabase armazena esse hash para permitir localizar o dispositivo quando alguém informa o código. O código original não é enviado ao Supabase, ao servidor de sinalização nem aos outros usuários. Por meio do backend e do painel do Supabase, o desenvolvedor não recebe o código original e não consegue recuperá-lo de forma prática a partir do hash, graças à entropia dos 27 caracteres aleatórios. Códigos antigos de oito caracteres são substituídos por um novo código ao atualizar/ativar o modo automático.

Para encaminhar conexões, o servidor também processa identificadores técnicos aleatórios e pseudônimos dos dispositivos e das sessões, além do nome de exibição escolhido ou detectado. O administrador técnico do serviço pode processar esses identificadores e os hashes necessários ao roteamento; eles não são o ID PC- do modo automático e não permitem recuperar esse código de forma prática. O servidor pode associar temporariamente o hash do ID automático ao dispositivo conectado para entregar o pedido, mas não recebe o código original. Outros usuários não recebem o código PC- nem o hash de consulta. Se você enviar uma avaliação ou feedback, os dados preenchidos serão encaminhados ao serviço utilizado para receber esse feedback.

3. Arquivos transferidos

O Physical Cloud foi projetado para transferir arquivos diretamente entre os dispositivos conectados. O conteúdo dos arquivos não é enviado ao servidor de sinalização como parte do fluxo normal de transferência. O dispositivo destinatário recebe o arquivo enviado pelo outro dispositivo. O usuário deve considerar que redes, sistemas operacionais, versões e configurações podem afetar o funcionamento da conexão.

4. Escolha de conexões e compartilhamento

Você decide com quem se conectar, quais solicitações aceitar, quais pastas disponibilizar e quais arquivos enviar. Não compartilhe códigos ou IDs com pessoas desconhecidas. A ativação do modo automático pode permitir que solicitações compatíveis sejam aceitas sem uma confirmação individual, conforme a configuração do recurso.

5. Segurança e arquivos maliciosos

O Physical Cloud não garante que arquivos enviados por terceiros estejam livres de vírus, malware, spyware ou qualquer conteúdo nocivo. Não há garantia de análise antivírus ou certificação de segurança dos arquivos. Mantenha seu sistema e seu antivírus atualizados e verifique os arquivos recebidos antes de abri-los.

6. Compartilhamento com terceiros e retenção

Dados técnicos podem ser processados pela infraestrutura necessária para operar a sinalização e receber feedback. O Physical Cloud não deve ser usado para transmitir dados pessoais ou confidenciais sem que você tenha autorização e compreenda os riscos. Dados locais podem ser removidos ao apagar os dados do aplicativo ou desinstalá-lo, conforme o sistema operacional.

7. Alterações e contato

Esta política pode ser atualizada para refletir mudanças no aplicativo ou exigências legais. A versão vigente será disponibilizada nesta tela ou nos canais oficiais de distribuição do Physical Cloud.
